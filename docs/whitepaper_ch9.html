30分钟环境搭建指南
从零开始装好 Claude Code + DeepSeek API，安装 5 个开箱即用的 AI Skills。不需要写一行代码，跟着走就行。
9 . 1
安装 Claude Code（终端 Agent）
Claude Code 是 Anthropic 推出的终端 AI Agent，能直接操作文件系统、运行命令、执行多步任务。它是运行所有 Skills 的基础环境。
M A C O S
1
安装 Node.js 18+（如未安装）
打开终端（Terminal），先跑 node --version。如果显示 v18 以上版本，跳过此步。否则去 nodejs.org 下载 LTS 版安装。
2
全局安装 Claude Code
npm install -g @anthropic-ai/claude-code
一行命令装好。安装完成后在终端输入 claude 即可启动。
3
安装 Playwright（截图用，可选）
pip3 install playwright
python3 -m playwright install chromium
W I N D O W S
同样先装 Node.js → 打开 PowerShell 跑 npm install -g @anthropic-ai/claude-code。如果遇到权限问题，以管理员身份运行 PowerShell。
T I P
macOS 用户也可以用 Homebrew 一键装 Node.js：brew install node。装完 Node 后全程不超过 5 分钟。

DeepSeek API 注册与配置
白皮书中所有案例、Skills、自动化流程都通过 DeepSeek API 驱动。性价比最高的选择——能力和 GPT-4 同级别，价格不到 1/10。
9 . 2
注册并获取 API Key（5 分钟）
1
注册 DeepSeek 账号
打开 platform.deepseek.com，用邮箱或 Google 账号注册。
2
进入 API Keys 页面
左侧菜单 → API Keys → 点击「创建 API Key」，复制保存。⚠️ Key 只显示一次，务必存好。
3
充值 ¥10 起
左侧菜单 → Billing → 充值。DeepSeek 按量计费，¥10 够个人用一个月以上。
9 . 3
配置 Claude Code 使用 DeepSeek
Claude Code 默认使用 Anthropic 官方 API。我们要让它走 DeepSeek 的 Anthropic 兼容端点。在终端中设置以下环境变量：
# 添加到 ~/.zshrc (macOS) 或 ~/.bashrc (Linux/WSL)
export ANTHROPIC_API_KEY="sk-你的DeepSeek-API-Key"
export ANTHROPIC_BASE_URL="https://api.deepseek.com/anthropic"
export ANTHROPIC_MODEL="deepseek-v4-pro[1m]"

# 保存后刷新
source ~/.zshrc
配置完成后，在终端输入 claude，看到 Claude Code 的交互界面就说明通了。
为 什 么 用 DeepSeek 而 不 是 官 方 Claude API
DeepSeek-V4 在 Anthropic 兼容模式下性能接近 Claude Opus 4，但价格仅为官方 API 的 1/8–1/10。对个人和小团队来说，这是目前性价比最高的方案。百万 token 不到 ¥2，跑一次 AI News 周报全流程只花约 ¥0.5。

安装 AI Skills + 跑通验证
5 个开箱即用的 Skills 直装到你的 Claude Code。每个 Skill 都是一份 Markdown 文件，装好就能用。
9 . 4
安装 5 个 AI Skills（2 分钟）
确保已安装 GitHub CLI（brew install gh 或从 github.com/cli/cli 下载），然后依次运行：
# 1. AI News 周报 — 邮箱拉取→聚合→精选→卡片→发布
gh skill install summersalt827/ai-news-weekly

# 2. AI Skills 深度 — 紫色长图文卡片 (cover+p1~p5)
gh skill install summersalt827/ai-skills-deep-dive

# 3. AI 内容工厂 — 一句话生成工具介绍卡片
gh skill install summersalt827/xhs-content-engine

# 4. 设计风格提取 — 截图→Token→组件→套用
gh skill install summersalt827/design-style-reference

# 5. 竞品参考 — 5个项目分析 + P0-P3优化表
gh skill install summersalt827/ai-competitive-reference
9 . 5
验证跑通
装好后，在 Claude Code 中试着说一句话来验证：
✓ 验 证 命 令
AI Skills，帮我做一个选题：
"普通人如何用 AI 提升工作效率"
如果 Claude Code 开始读取 AI Skills 的 Skill 定义、生成卡片结构，说明整个环境搭建成功了。
